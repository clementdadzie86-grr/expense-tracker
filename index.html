Section 1

What is an Array?

An array is a data structure that stores a collection of values in a single variable. Each value sits in a numbered slot, so the whole collection can be accessed, searched, and updated efficiently.

[0]

Index-based storage

Every element has a position called an index, starting at 0. Looking up arr[2] takes constant time, O(1).

1→2→3

Ordered collection

Elements keep the order in which they were inserted, which makes arrays ideal for lists, timelines, and rankings.

+/−

Dynamic manipulation

In JavaScript, arrays grow and shrink at runtime. Methods like push, filter, map and reduce make this easy.

Length = 5. The last valid index is always length - 1.

Basic syntax
// Create an array
const prices = [10, 25, 5];

// Access by index (starts at 0)
console.log(prices[0]);       // 10
console.log(prices.length);    // 3

// Update an element
prices[1] = 30;

// Array of objects (used in our tracker)
const transactions = [
  { title: "Salary", amount: 2000, type: "income" },
  { title: "Coffee", amount: 4.5,  type: "expense" }
];
Key operations
const nums = [5, 12, 8];

// push: add to the end
nums.push(20);                    // [5, 12, 8, 20]

// filter: keep items that match a rule
const big = nums.filter(n => n > 8); // [12, 20]

// map: transform every item
const doubled = nums.map(n => n * 2);

// reduce: collapse to a single value (total)
const total = nums.reduce((sum, n) => sum + n, 0);
console.log(total);               // 45

// splice: remove by index
nums.splice(1, 1);                 // removes 12

Section 3

Why Arrays are Required for the Expense Tracker

An expense tracker has to remember a growing list of records and answer questions about them. That is exactly what arrays are built for.

① Storing a dynamic list of transactions

Users add transactions at any time, so we can't know the count in advance. A JavaScript array of objects holds any number of records, and push() appends each new one.

② Calculating running balances

Totals for income, expenses and balance come from reduce(), which walks the array once and accumulates a result.

③ Filtering by type and category

Showing only expenses, or only "Food", is a single filter() call that returns a new array without touching the original.

④ Rendering the user interface

The transaction list on screen is produced by map(), which turns each data object into a row. The array is the single source of truth and the UI is just a view of it.

⑤ Deleting records safely

Removing a transaction means building a new array without it, with filter(t => t.id !== id) (or splice() by index).

⑥ Persisting data

An array converts neatly to JSON with JSON.stringify() for localStorage, and back again with JSON.parse(), so data survives a page refresh.
